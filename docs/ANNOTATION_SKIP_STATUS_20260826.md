# Human annotation status

Human annotation was intentionally skipped for the 2026-08-26 release because
annotators were unavailable.

The 600-row CIRR mechanism queue, 100-row double-annotation overlap sheet, and
400-row intent-review sheet are retained as blank audit materials only. The
caption-only preannotations and automatic intent labels are not human labels
and are not used to report category-specific mechanism, agreement, or causal
results.

Accordingly, this release reports the automated rank-delta, lexical intent,
generation-quality, and matched-control evidence only. Any future human-label
analysis must recompute agreement and category-level results from the blank
sheets before adding those claims.
