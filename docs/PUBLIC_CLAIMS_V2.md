# Public claims v2

The local evidence supports the following restrained statement:

> We did not reproduce the reported ConText-CIR headline result under the
> documented local implementation and protocols. In the tested local path,
> the default Text-CC threshold was inactive and the unthresholded signal was
> very small. Adding LaSCo to a locally reconstructed ViT-B/no-Text-CC data
> composition improved the local result under an approximately matched budget,
> but did not recover the reported performance.

This is a bounded technical reproducibility report. It is not a claim about
author intent, research integrity, or every possible implementation,
backbone, budget, or preprocessing configuration.
